# Gifjes voor een nieuwe aanvraag

Naar Marketing, als er een aanvraag binnenkomt: "incoming".

Zet hier een `.gif` neer en hij gaat vanzelf mee: elke mail kiest willekeurig een gifje uit deze map.
Is de map leeg, dan krijgt de mail geen gifje. Hoe je er een toevoegt staat in de
[uitleg een map hoger](../README.md).
